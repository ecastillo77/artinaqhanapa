Entrar al panel

Los cambios se guardan en el repositorio de GitHub de la web y se publican solos en www.artinaqhanapa.com en un minuto. Para eso necesitas una clave de acceso de GitHub.

¿Cómo obtengo la clave? (solo la primera vez)
  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta ecastillo77.
  2. Nombre: Panel Artina Qhanapa. Vencimiento: el que prefieras (por ejemplo 1 año).
  3. En Repository access elige Only select repositories y marca artinaqhanapa.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Toca Generate token, copia la clave y pégala arriba.

La clave solo sirve para este repositorio. No la compartas. Si la pierdes o vence, crea otra igual.
