# Plan: web propia de Artina Qhanapa

Meta: tener antes de fin de 2026 una web propia para exponer y vender las obras del colectivo.
Contexto: colectivo de Tacna, Perú. Ventas solo dentro del Perú. Presupuesto mínimo.
Página actual: https://www.facebook.com/p/Artina-Qhanapa-61591239882374/

Decisiones:
- Web gratuita con galería, ficha por obra y botón "Comprar por WhatsApp".
- Cobro con Yape/Plin (QR) y transferencia bancaria.
- Envíos por agencia (Shalom, Olva), pagados por el comprador; entrega o recojo en Tacna.
- Dominio .com opcional (aprox. S/ 40-60 al año).

Pasos (aprobados por Qiqin el 01/11/2026):
1. Contenido (semanas 1-2): fotos y datos de cada obra, artistas, historia, contacto.
2. Diseño (semanas 2-4): primera versión para revisión.
3. Publicación (semanas 4-6): web en línea con compra y pago.
4. Lanzamiento (semanas 7-8): difusión en redes y enlace desde Facebook.
